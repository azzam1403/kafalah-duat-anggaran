PAKET PWA - Anggaran Memo Kafalah Duat (struktur datar, TANPA folder)

FILE (semua harus ada di akar repository, sejajar, tanpa subfolder):
  index.html, manifest.json, sw.js,
  icon-192.png, icon-512.png, icon-maskable.png, apple-touch-icon.png,
  cek.html (alat pemeriksa, opsional)

CARA UNGGAH DI GITHUB
1. Ekstrak zip ini dulu.
2. Di repository: Add file > Upload files > "choose your files", lalu PILIH SEMUA FILE (Ctrl+A) di folder hasil ekstrak. Tidak ada folder yang perlu diunggah.
3. Commit changes. Tunggu 1-2 menit sampai Actions berwarna hijau.
4. Buka  https://azzam1403.github.io/kafalah-duat-anggaran/cek.html  untuk memastikan semua file terbaca.
5. Hapus file lama yang tidak dipakai lagi (boleh): folder icons, manifest.webmanifest.

CARA PASANG
- Android: buka alamat utama di Chrome, tunggu beberapa detik, lalu menu (tiga titik) > "Instal aplikasi". Kalau muncul tombol "Pasang" di pojok atas aplikasi, boleh pakai itu.
- Laptop: ikon pasang di address bar.
- iPhone: Safari > Bagikan > Tambahkan ke Layar Utama.
Jika sebelumnya sudah terpasang dengan ikon lama, hapus (uninstall) aplikasi itu lebih dulu lalu pasang ulang.

Saat mengubah index.html: naikkan nama cache di sw.js (kafalah-v13 -> kafalah-v14) supaya perangkat mengambil versi baru.
